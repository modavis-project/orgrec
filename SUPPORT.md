# Support

OrgRec is research software. There is currently no guaranteed support period or
response time. Released VAO packages follow the versioned VAO compatibility
declaration; editable OrgRec project compatibility is documented per release.

After the repository becomes public, use GitHub issues for reproducible bugs,
documentation problems, and narrowly scoped feature proposals. Do not attach
private recordings, unpublished datasets, venue details, personal data, or
security-sensitive files to public issues.

Security reports follow [SECURITY.md](SECURITY.md). Questions about the VAO
standard should identify the exact format version and should not be filed as an
OrgRec application bug unless the application's behavior is involved.
