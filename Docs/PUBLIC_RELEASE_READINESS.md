# Release status

OrgRec 0.3.2, build 13, provides a universal macOS application and its matching
source release. Distribution links are maintained in the repository README
and CITATION.cff.

## Compatibility

- macOS 14 or later, on Apple Silicon and Intel Macs.
- The published POD 1.6.0 OrgRec projection, with the pinned 1.5.0 projection
  retained as a supported source. The database is distributed separately.
- VAO 0.5.0 preservation-closure export, with exact historical readers retained
  for the supported earlier format versions.
- Local audio-file analysis without a project, catalogue or microphone access.

## Verification and distribution limits

Automated verification covers Swift processing and application state, database
identity and queries, source preservation, standalone reports and data exports,
VAO reference conformance, source boundaries and REUSE licensing. Exported
figures and report pages have also been rendered and inspected.

The macOS binary is ad-hoc signed and is not notarized. Clean-install Finder
drag-and-drop, physical audio interfaces and field recording setups require
separate user-environment verification. These limits do not alter the preserved
measurement provenance or imply calibrated acoustic accuracy.

## Publication contents

The release contains source code, synthetic test fixtures, documentation,
licenses and the packaged application. Private recordings, local research
outputs, workstation paths, temporary verification files and unpublished models
are excluded. Identified third-party components retain their licenses and
scientific attribution.
