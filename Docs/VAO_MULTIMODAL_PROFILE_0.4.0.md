# VAO Multimodal Timeline profile 0.4.0

Profile IRI: `https://w3id.org/modavis/vao/profile/multimodal/0.4.0`

The profile is required when any timebase, track, synchronization mapping, or annotation is present. Every track references an exact realization and timebase. Spatial tracks also identify their coordinate frame. Clock conversion is piecewise affine, uncertainty-bearing, activity-derived, and discontinuity-aware.

IIIF Canvas and Web Annotation are normative projection targets for presentation. MEI is the preferred score/performance binding. VAO retains preservation identity, clock evidence, and cross-instrument semantics that those presentation formats do not attempt to replace.
