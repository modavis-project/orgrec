# VAO Zenodo repository profile 0.4.0

Profile IRI: `https://w3id.org/modavis/vao/profile/repository/zenodo/0.4.0`

Zenodo remains an optional adapter. Repository-free, embedded, BagIt, OCFL, and other exact distributions remain valid. Exact acquisition uses a version record/file identity, never a mutable concept DOI.

The 0.4.0 projection retains the 0.3.3 modular-record and explicit-record-family choices and is supplemented by repository-neutral `discovery` metadata. Creators/contributors resolve to typed Agents with ORCID/ROR where available; funding and related identifiers project to current DataCite kernel fields. Repository metadata cannot change the VAO semantic release.
