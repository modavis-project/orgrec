# VAO 0.4.0 release checklist

## Implemented private-draft gates

- [x] Immutable exact-version schema/context/vocabulary/SHACL bundle with checksums.
- [x] Typed scientific provenance and reproducibility records.
- [x] General multimodal and annotation model.
- [x] Physical instrument topology.
- [x] Deterministic runtime semantics and reference interpreters.
- [x] MIDI 2, rich transfer functions, delayed-cycle policy.
- [x] Large-dataset chunking and digest agility.
- [x] Consent, community governance, discovery, and redaction semantics.
- [x] RO-Crate, DataCite, IIIF, OCFL, JSON-LD, and SHACL artifacts.
- [x] Python and Swift models, validators, tests, and Kinoorgel fixture.
- [x] 0.3.3-to-0.4.0 evidence-preserving private migration.
- [x] Legacy 0.2 and 0.3 regression suites retained.

## Public-standard gates

- [ ] Named governance/editorial approval.
- [ ] W3ID redirects deployed and independently tested.
- [ ] Media-type registration strategy approved.
- [ ] MODAVIS release and mapping checksum-pinned.
- [ ] Specification/source licenses approved.
- [ ] At least two implementations developed independently of this repository.
- [ ] External scientific, cultural-rights, accessibility, and security review.
- [ ] Cross-instrument corpus and scale/performance report.

Until the second section is complete, 0.4.0 is an implemented private editor's draft rather than an approved public standard.
