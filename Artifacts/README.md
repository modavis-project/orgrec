# Local generated artifacts

This directory is reserved for local research outputs, converted sample sets,
and preservation carriers. Its contents are excluded from the public OrgRec
source repository because they may be large, machine-specific, independently
citable, or governed by source-data licenses.

Documentation and tools may use paths below `Artifacts/` as reproducible output
locations. A local checkout can retain those files, but public software release
archives contain only this notice. Publish a research result or dataset in its
own reviewed record with its own provenance, license, and checksums.
