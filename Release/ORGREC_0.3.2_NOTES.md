# OrgRec 0.3.2

OrgRec 0.3.2 adds direct audio-file analysis and supports the published POD 1.6.0
organ catalogue. The macOS application is version 0.3.2, build 13, for Apple
Silicon and Intel Macs running macOS 14 or later.

## Analyze Audio

Drop one audio file onto OrgRec, open it through Finder, or choose
**File → Analyze Audio File…**. Short files are analyzed automatically; longer
recordings offer explicit excerpt selection. No project, catalogue, account or
microphone access is required.

The workspace provides channel and sound-type controls, an optional reference
pitch, linked waveform and spectral plots, pitch-estimator evidence, signal
quality, boundaries and complete measurement inspection. PDF, JSON, CSV, PNG
and SVG exports are available. A complete export folder includes the analyzed
excerpt, provenance and checksums. The original recording stays unchanged.

## Catalogue and first use

The optional POD 1.6.0 database can be downloaded from its prefilled Zenodo URL,
verified, expanded and cached for offline search and recording roadmaps. The
pinned POD 1.5.0 projection remains supported with its original source identity.

Getting Started explains catalogue installation, local project options,
microphone permissions, recording setup and test recordings. Project loading is
deferred while a new user remains in Getting Started or Analyze Audio.

## Distribution and interpretation

The app is ad-hoc signed and is not notarized. Clean-install Finder drag-and-drop
and physical capture hardware have not been verified for this release.
Unknown-source pitch interpretations are provisional; single-file analysis does
not supply missing organ, calibration, geometry or collection evidence.

The matching source and universal application archives are distributed with
SHA-256 checksums. License terms and third-party attribution are included.
